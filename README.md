**Observações**

**1.** Todas as regras abaixo descritas deverão ser cumpridas **sem exceções**. O rompimento de qualquer uma delas acarretará em **punições determinadas única e exclusivamente pela Administração do Vila Carioca**.

**2.** Este documento contém todas as regras para o bom e saudável funcionamento e andamento do servidor. Qualquer regra que **não esteja neste livro de regras não se aplica ao sistema de punições**, a menos que orientado especificamente por um administrador competente. _(Importante sempre guardar provas das orientações recebidas)._

**3.** A data da última atualização das regras constará sempre no nome do arquivo. Dessa forma, é fundamental que os players estejam constantemente atualizados das regras e suas alterações/atualizações.
